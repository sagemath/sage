elliptic_curves: Databases of elliptic curves
=============================================

Description
-----------

Includes two databases:

-  A small subset of John Cremona's database of elliptic curves up
   to conductor 10000.

-  William Stein's database of interesting curves


Python Package
--------------

Installed from https://pypi.org/project/sage-data-elliptic-curves/.
The Python distribution includes the data and provides an
``importlib.resources`` API.
